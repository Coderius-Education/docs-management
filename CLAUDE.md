# Richtlijnen voor Claude

## Commentaar in code
- Schrijf alleen commentaar als de reden niet uit de code zelf blijkt
  (een bewuste keuze, een workaround, een beperking van een externe dienst).
- Geen docstrings of commentaar die herhalen wat functienaam en code al zeggen.
- Geen scheidingsregels (`# --- ... ---`) of uitleg per teststap.
